## The driver page: what it means
Run `ref1` (plain QEMU, stock EDK2, no layer, the same image on an NVMe disk that Windows supports) stops on the **same** page [verified: `ref1/shot-0002.png`]. So the page does not prove that only a storage driver is missing: the image has no `install.wim`, and Setup shows this page even where the storage works. Cause [hypothesis]: Setup does not find the install files. This corrects the reading in `2026-11-24-ciani-01.md`.
The real `install.wim` is 7.5 GB, more than the M1's free RAM, so the RAM disk cannot hold it. A full install needs real storage (USB). Reaching the next pages may not.
